## 🗂️ Projetos em Destaque

### 📚 [Mainframe Assembly](https://github.com/diegoemoyses/Mainframe-Assembly)

Coleção de programas em Assembly para Mainframe IBM com explicações detalhadas:

| Programa | Descrição |
|----------|-----------|
| [**ASMALLC1.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/ASMALLC1.md) | Demonstra o uso da macro [`BPXWDYN`](https://www.ibm.com/docs/en/zos/2.4.0?topic=output-requesting-allocation-information) para dividir dinamicamente um arquivo a cada 70 registros |
| [**PASMBLN1.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/PASMBLN1.md) | Balance Line com ou sem correspondentes |
| [**ESTATI01.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/ESTATI01.md) | Cálculo de medidas de tendências centrais (moda, mediana e média) |
| [**CONTDSN.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/CONTDSN.asm) | Verifica a quantidade de registros em um dataset e exibe em SYSPRINT |
| [**ASMP0503.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/ASMP0503.asm) | Leitura de dados do cartão ENTRADA e exibição no cartão SAIDA |
| [**ASMPARM1.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/ASMPARM1.asm) | Recebe parâmetro via PARM do JCL e emite no WTO |
| [**ASMP0500.asm**](https://github.com/diegoemoyses/Mainframe-Assembly/blob/main/ASMP0500.asm) | Hello World em Assembly |
